# NyumbaFind 🏠

**NyumbaFind** is a frontend web application for **house hunting in Nairobi, Kenya**. It helps users search and explore available houses by location and property type.

## 🛠️ Technologies

* HTML5
* Tailwind CSS
* JavaScript

## ✨ Features

* Search houses by location
* Filter by property type
* View house details and prices
* Responsive design
* Nairobi locations and properties
